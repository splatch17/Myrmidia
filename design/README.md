# Design

- [`concept.html`](concept.html) — document de brainstorming principal : univers, castes jouables, pipeline 3D visé, piliers de gameplay, carte du monde, HUD, palette. À ouvrir dans un navigateur.
- [`prototypes/`](prototypes/) — prototypes jouables. Le premier, *Sortie de la Fourmilière*, met à l'épreuve l'échelle du monde, les deux caméras candidates et la locomotion hexapode procédurale.
- [`banner.svg`](banner.svg) — bannière du README racine : SVG autonome (aucune dépendance externe), une fourmi minuscule au pied de tiges d'herbe rétro-éclairées, dans la palette chitine/rouille/miel.

D'autres esquisses (moodboards, mockups d'écrans, exploration de biomes) viendront s'ajouter ici au fil du brainstorming.
